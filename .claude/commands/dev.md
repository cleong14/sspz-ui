---
name: dev
description: Start development server or Storybook
---

Start development environment for this project.

Options based on argument:
- No argument: Start Vite dev server
- `storybook` or `sb`: Start Storybook on port 6006

Commands:
- Dev server: `yarn dev`
- Storybook: `yarn storybook`

The dev server will start and you can access it at the URL shown in the output.
